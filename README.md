# 간호사 근무표

브라우저에서 동작하는 간호사 3교대(D/E/N) 근무표 자동 생성기입니다. 설치할 것 없이 정적 파일(HTML/CSS/JS)만으로 동작하며, 데이터는 브라우저(localStorage)에 저장됩니다.

## 실행

```bash
node server.js
```

브라우저에서 http://localhost:8765 을 엽니다. (`index.html`을 GitHub Pages 등에 그대로 올려도 됩니다.)

## 기능

- **간호사 명단**: 이름·등급(책임/일반/신규) 추가, 수정, 순서 변경, 삭제
- **근무 규칙**: 평일/주말·공휴일 근무별 필요 인원, 최대 연속 근무일, 최대 연속 나이트, 나이트 후 최소 휴무, 월 최소 휴무일, 근무마다 책임 간호사 1명 이상
- **자동 생성**: 금지 패턴(N→D, N→E, E→D)을 피하고 나이트·주말 휴무를 고르게 나누도록 여러 번 생성해 가장 좋은 안을 고릅니다. 지난달 근무표 끝부분도 이어서 고려합니다.
- **휴가 신청 폼**: 간호사·종류(V 연차/OFF 휴무)·시작일·종료일을 넣으면 기간 전체가 한 번에 고정됩니다. 달을 넘는 기간도 각 달로 나눠 저장되고, 목록에서 기간 단위로 삭제할 수 있습니다. V는 월 최소 휴무일과 따로 계산됩니다.
- **근무 신청**: ‘근무 신청’ 모드에서 칸을 클릭해 원하는 휴무/연차/근무를 하루씩 고정할 수도 있습니다.
- **직접 수정**: ‘근무 편집’ 모드에서 칸을 클릭해 D → E → N → OFF → 빈칸 순으로 변경
- **공휴일 지정**: 날짜 머리글을 클릭하면 공휴일로 지정되어 주말 인원 기준이 적용됩니다.
- **검증**: 인원 부족, 규칙 위반 칸을 빨간 테두리와 목록으로 표시
- **내보내기**: CSV(엑셀에서 열기 가능), 인쇄
